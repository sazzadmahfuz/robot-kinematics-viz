# Robot Arm Kinematics Visualizer

Interactive 3-DOF planar robot arm simulator supporting forward and inverse kinematics.

## Features
- Forward kinematics
- Inverse kinematics
- Interactive target selection
- Joint angle control
- Real-time animation
- Workspace visualization

## Technologies
- HTML5 Canvas
- JavaScript
- Robotics Kinematics
